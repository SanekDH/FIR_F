# Transposed FIR filter 

Реализация КИХ фильтра на яззыке system verilog.

## Особенности
- транспонированная архитектура.
- параметризация длины отсчётов входных данных, количества коэффициентов, длины коэффициентов (максимальная длина коэффициента - 32 бит).

## Структура проекта
- `src/Fir_F.sv` — модуль фильтра.
- `sim/testbench_FIR.sv` — testbench.
